# 📊 Customer Behavior Analysis

## 🧠 Overview
This project analyzes customer shopping behavior to uncover key insights into purchasing patterns, customer segmentation, and revenue trends. The goal is to support data-driven business decisions.

## 🎯 Objective
To identify patterns in customer behavior, product performance, and revenue contribution using data analysis and visualization techniques.

## 🛠️ Tools Used
- Python (Pandas, NumPy)
- SQL
- Power BI

## 📁 Dataset
- 5000 customers
- 30 unique products
- Includes demographics, transactions, ratings, and purchase details

## 🔄 Workflow
1. Data Cleaning (Python)
2. Data Transformation (SQL)
3. Data Visualization (Power BI Dashboard)

## 📊 Key Insights
- Electronics generated the highest revenue (~0.49M)
- Age group 46–60 contributes the most (~30%)
- Top products: Headphones, Phone, Watch
- Most revenue from New York, Los Angeles, Chicago
- Debit Card & Cash are most used payment methods
- Fall season shows lowest revenue

## 📈 Features
- Interactive dashboard
- KPI tracking
- Customer segmentation
- Product performance analysis
